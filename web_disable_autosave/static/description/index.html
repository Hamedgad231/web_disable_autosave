Disable Auto Save

Odoo saves a record by itself as soon as the user leaves it. With this app nothing is saved until the user clicks Save.

Odoo Community Odoo Enterprise Odoo.sh

Why this app?

A wrong value typed by mistake, a click on the menu, a reload of the page... and Odoo has already saved the record. This app gives the control back to the user: the changes are kept only when the user clicks Save, otherwise the user is asked to discard them or to stay on the record.

Features

Leaving the record
Breadcrumb, menu, browser back button or a link: the user is asked to discard the changes or to stay on the record.
Reload or close the browser tab
The browser warns the user before leaving the page, and nothing is saved when the user leaves anyway.
Switching browser tabs
Odoo no longer saves the record when the user switches to another browser tab or window.
Pager and New button
Next / previous record and the New button ask to discard the changes or stay, instead of saving.
Editable lists
A click outside of a changed row keeps it in edition, and leaving the page asks to discard the row or stay.
Zero configuration
Install the app and it works in every application and every model. Translated into all 93 Odoo languages, covered by automated tests.

See it in action

1The user changes a record

The record is not saved: the cloud icon shows the changes are pending until the user clicks Save.

2Leaving the record asks first

A click on the breadcrumb (or the menu, a link, the back button) opens the Unsaved changes dialog: Discard changes or Stay here.

3Next record, previous record and New

The pager arrows and the New button ask the same question instead of saving the current record.

4Editable lists keep the row in edition

Clicking outside of a changed row no longer saves it: the row stays in edition until the user clicks Save or Discard.

5Leaving a list with a changed row

Opening another menu while a row is changed asks to discard the row or to stay on the list.

Reload, close and other browser tabs

Reloading or closing the tab shows the browser's own "Leave site?" warning, and nothing is saved if the user leaves. Switching to another browser tab keeps the changes on screen without saving them.

Installation

1. Download

Put the web_disable_autosave folder in your addons path.

2. Install

Update the apps list and install Disable Auto Save.

3. Done

No settings: every form and editable list now saves only with the Save button.
